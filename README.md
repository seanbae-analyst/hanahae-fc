# HANA HAE FC · Dues Ledger

A mobile-first dues ledger and weekly cash-flow forecast for a recreational football club.

- Live demo (names anonymized): https://seanbae-analyst.github.io/hanahae-fc/demo.html
- Upload a bank statement (Excel) → transactions are de-duplicated and categorized from memos
- Dues tracking per member with club-rule late fees and inactive members
- Driver-based weekly cash-flow forecast with base / downside / upside scenarios and sensitivity table
- Runs as a single static HTML file (no server, no login); officers publish updates with one tap
